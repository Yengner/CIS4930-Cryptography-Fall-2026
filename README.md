# CIS 4930/6930 - Cryptography, Theory and Practice (Fall 2026)

Shared semester repository for homework assignments.

## Organization

Each homework gets its own folder:

- `HW1/` - Homework 1
- `HW2/` - Homework 2 (when assigned)
- etc.

For each assignment, keep the source code, assignment-specific notes, and testing instructions inside that homework folder.

## Team workflow

1. Pull the newest changes before starting.
2. Create or edit files only inside the current homework folder.
3. Make small commits with clear messages.
4. Push your branch/changes so your teammate can review them.
5. Avoid committing compiled programs and generated output files.
